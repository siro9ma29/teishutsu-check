# 【提出チェックアプリ】引き継ぎメモ（2026-11-17・v1.2）

- 目的・使う人：担任が教務に出す提出物（週案・指導要録などの書類、集金・調査の回答、通知表・所見）を、クラスごとに「提出済／未提出＋提出日」で記録する。使うのは教務だけ。
- できていること（v1.2）：
  - チェックの単位を「学級ごと／学年ごと」から選べる（v1.2）。設定タブで新しい提出物の初めの単位を決め、提出物ごとに登録・編集の画面で変えられる。学年ごとでは枠が学年に1つ（特別支援学級はまとめて1つ）、一覧表ではその学年の列をつないだ1マス、催促の文は「まだ提出されていない学年」
  - 提出物ごとにタブを作り、タブを切り替えてチェックする（v1.1。タブに締切・提出数・未提出数を表示、締切後の未提出があるタブは上が赤）
  - 設定：1〜6年の組の数と特別支援学級の名前からクラスを作る。担任名（任意）。提出物の種類の編集
  - 提出物の登録・編集・複製・削除（名前・種類・締切日・出すクラス・メモ）
  - クラスの枠を押すと提出済（今日の日付）、もう一度で未提出。日付は枠の中で直せる
  - 締切を過ぎた未提出は赤、締切が今日・明日なら「締切が近い」
  - 全クラス提出済の提出物は一覧から自動で隠す
  - 「未提出のクラスを文にする」で催促の文をコピー
  - 一覧表（提出物×クラス）、印刷
  - JSONでバックアップ・復元。年度切り替え（提出物を全部消す前に自動バックアップ）
- 決めた仕様（理由も一言）：
  - 1つのHTML・オフライン（教務だけが付けるので共有不要。学校の端末で動く）
  - クラスを作り直しても、同じクラス名（例：3-1）は提出記録と担任名を引き継ぐ（年度途中の学級増減に対応）
  - 学年ごとの提出物は「学年」で記録する（done のキー g1〜g6、g0＝特別支援学級）。年度途中で組が増えても、そのまま学年の枠に入る
  - 単位を変えても今までのチェックは消さない（表示されなくなるだけ。戻せば元に戻る。確認を出す）
  - v1.1 までの提出物（unit がない）は学級ごととして扱う
  - 複製はクラスの設定を引き継ぎ、締切と提出記録は空にする（毎週の週案を楽に作るため）
- 未解決・次にやること：
  - 他アプリ（週案作成アプリなど）の設定からクラス・担任名を読み込む（必要なら）
  - 児童ごとの提出物の管理は今回は対象外
- ファイル名／GitHubの場所：index.html ／ https://github.com/siro9ma29/teishutsu-check（予定）
- 後任向けの注意点：
  - データはブラウザの localStorage（キー：teishutsu_data）だけにある。履歴を消すと消えるので、学期末にバックアップを取る
  - 引き継ぐときは index.html とバックアップのJSONを渡し、「設定・バックアップ」→「ファイルから復元」
